# Reference Workflows

This sample app uses public retailer-portal material only as a functional reference. It does not copy brand assets, page layouts, legal text, private screens, or proprietary naming from any external portal.

## Publicly Observed Patterns

- Secure retailer sign-in with a password reset path and help messaging.
- Account-specific catalog access with pricing and inventory availability.
- Order history with status, delivery tracking, and fulfilment documents.
- Downloadable operational and financial documents such as acknowledgements, shipment notices, invoices, credits, and statements.
- Multi-location account maintenance with contacts and communication preferences.

## Sample-App Interpretation

- Products remain generic B2B supply items.
- Locations remain generic customer locations.
- Documents are generated mock records linked to orders, shipments, invoices, credits, and statements.
- Password reset, delivery tracking, and profile publication status are simulated for demo purposes.
- Training, marketing-asset, promotion, certification, and brand-content libraries are intentionally out of scope.
